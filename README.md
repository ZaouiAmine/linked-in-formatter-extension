# LinkedIn Post Formatter Extension

Format LinkedIn posts with rich text formatting using Unicode symbols.

## Quick Installation

### Chrome (Easiest)

1. Open `chrome://extensions/`
2. Toggle "Developer mode" ON (top-right)
3. Click "Load unpacked"
4. Select this folder

Done! The extension works automatically on LinkedIn.

### Firefox

1. Open `about:debugging`
2. Click "This Firefox" → "Load Temporary Add-on"
3. Select `manifest.json` from this folder

Done! The extension works automatically on LinkedIn.

## Reload After Changes

**Chrome:** `chrome://extensions/` → Click refresh icon  
**Firefox:** `about:debugging` → Click "Reload"
